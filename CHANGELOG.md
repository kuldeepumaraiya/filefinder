# Changelog

## 2.0.0

- Standalone Windows x64 desktop build with a custom taskbar icon.
- Modern folder sidebar, live search, category filters, sorting, and text previews.
- Persistent SQLite FTS index with filename-first indexing and pausing.
- PDF, modern Office, OpenDocument, text, and source code extraction.
- Unicode and long Windows path support.
- Per-user installation helper and portable distribution.
