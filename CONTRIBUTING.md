# Contributing to FileFinder

Thanks for helping improve FileFinder for Windows users.

## Report a problem

Use the [bug report form](https://github.com/kuldeepumaraiya/filefinder/issues/new?template=bug_report.yml). Include your FileFinder and Windows versions, steps to reproduce, the expected result and the file format involved. A small synthetic example is useful. Do not upload personal documents, search databases or logs containing private paths or text.

## Suggest a feature

Use the [feature request form](https://github.com/kuldeepumaraiya/filefinder/issues/new?template=feature_request.yml). Describe the task you want to complete and how the change would help.

## Submit a change

1. Fork the repository and create a branch for your change.
2. Follow the [development guide](docs/DEVELOPMENT.md) to run the app and relevant checks on Windows.
3. Keep the change focused. Add a regression test when fixing search, indexing or preview behavior.
4. Update documentation when the user-facing behavior changes.
5. Open a pull request explaining the problem, the change and how you verified it.

Keep generated builds, private indexes, logs and local credentials out of commits. Dependency additions must include their applicable license notices.
